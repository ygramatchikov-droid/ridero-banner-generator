# Вопросы для админа Ridero (хостинг генератора баннеров)

Привет! Мы делаем внутренний инструмент — генератор баннеров для авторов.
Сейчас он работает локально, скоро нужно будет перенести на хостинг Ridero.

Вот что нужно знать для переноса:

---

## 1. Сервер

- Какой сервер выделяется? (VPS, Docker-кластер, Kubernetes, bare metal?)
- Какая ОС на сервере? (Ubuntu, CentOS, Debian?)
- Сколько оперативки и CPU доступно?
- Есть ли Docker на сервере? Или нужно ставить?

## 2. Домен и SSL

- На каком домене будет жить? (например, `banner.ridero.ru`)
- SSL-сертификат — вы выпускаете или нам самим через Let's Encrypt?
- Есть ли Nginx / reverse proxy перед приложением, или нам самим настраивать?

## 3. Сеть

- Какие порты открыты наружу? (нужен 80/443)
- Есть ли ограничения на исходящие запросы? (приложение ходит на ridero.ru за данными книг и обложками)
- Есть ли firewall / VPN для доступа к серверу?

## 4. CI/CD

- Как деплоить? (SSH + git pull? Docker registry? Jenkins? GitLab CI?)
- Есть ли уже pipeline для других проектов, к которому можно подключиться?
- Доступ к серверу — по SSH-ключу или через VPN?

## 5. База данных (на будущее)

- Есть ли общий PostgreSQL-сервер, к которому можно подключиться?
- Или нужно поднимать свою БД? (для трекинга QR-переходов в будущем)

## 6. Мониторинг

- Есть ли общий мониторинг (Grafana, Prometheus, Zabbix)?
- Куда складывать логи?

---

Спасибо! По ответам подготовим Docker-образ и инструкцию по деплою.
