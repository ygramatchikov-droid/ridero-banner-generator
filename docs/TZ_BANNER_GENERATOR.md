# Техническое задание: Генератор баннеров Ridero

**Версия:** 1.0
**Дата:** 15 января 2026
**Статус:** MVP для тестирования

---

## 1. Общее описание

**Название проекта:** Генератор баннеров для авторов Ridero

**Цель:** Веб-приложение, позволяющее авторам книг за 2–3 клика создать баннер для соцсетей и скачать его для публикации.

**Целевые платформы:** ВКонтакте, Telegram, TenChat

**Целевая аудитория:** Авторы книг Ridero (не дизайнеры, нужен максимально простой интерфейс)

---

## 3. Функциональные требования

### 3.1 Пользовательский путь (User Flow)

```
ШАГ 1: Ввод ссылки на книгу Ridero
         ↓
ШАГ 2: Выбор типа баннера (О книге / Презентация)
         ↓
ШАГ 3: Выбор форматов (квадратный, вертикальный, OG)
         ↓
ШАГ 4: Выбор цветовой схемы (6 вариантов)
         ↓
ШАГ 5: Предпросмотр и редактирование текста
         ↓
ШАГ 6: Скачивание (отдельные файлы или ZIP)
```

### 3.2 Форматы изображений

| Формат | Размер | Использование | Имя файла |

| Вертикальный | 1080×1920 px | Истории VK, TenChat | `book_story_1080x1920.png` |
| Превью ссылки | 1200×630 px | OG-изображение | `book_og_1200x630.png` |

### 3.4 Элементы баннера

**Обязательные элементы (тип "О книге"):**
- Обложка книги (фиксированное расположение по шаблону)
- Название книги
- Имя автора
- Краткая аннотация (до 200 знаков)
- QR-код со ссылкой на книгу (с трекингом)
- Логотип Ridero

**Дополнительные элементы (тип "Презентация"):**
- Заголовок: "Встреча с автором" / "Презентация книги"
- Дата и время
- Место проведения

## 4. API-интеграции

### 4.1 Ridero API (заглушка для MVP)

**Запрос:**
```json
{
  "url": "https://ridero.ru/books/budni_veterinarnogo_vracha/"
}
```

**Ответ:**
```json
{
  "title": "Будни ветеринарного врача",
  "author": "Иван Петров",
  "coverUrl": "https://example.com/cover.jpg",
  "annotation": "Захватывающие истории из практики ветеринара...",
  "genre": "Нон-фикшн",
  "bookUrl": "https://ridero.ru/books/budni_veterinarnogo_vracha/",
  "freeFragmentUrl": "https://ridero.ru/books/budni_veterinarnogo_vracha/read/"
}
```

**Важно:** На этапе MVP используем мок-данные. При интеграции с реальным API Ridero заменяем `lib/mock-books.ts`.

### 4.2 QR-код с трекингом

**Механизм (будущее):**
1. При генерации баннера создаётся уникальный `tracking_id`
2. QR-код ведёт на: `https://banner.ridero.ru/go/{tracking_id}`
3. Редирект + запись перехода в БД
4. Конечный URL: ссылка на бесплатный фрагмент книги

**MVP:** Прямая ссылка на книгу без трекинга.

## 5. Требования к дизайнеру

### 5.1 Что нужно подготовить

**Шаблоны баннеров (в Figma):**

Для каждого формата (квадратный, вертикальный, OG) нужно:
- 3-4 варианта композиции (расположение обложки, текста, QR)
- Каждый вариант в 6 цветовых схемах

**Требования к макетам:**
1. Использовать только Google Fonts (рекомендуемые: Montserrat, Open Sans)
2. Оставить зоны для переменного контента (название, автор, аннотация)
3. QR-код: 80-120 px минимум, не перекрывать текст
4. Логотип Ridero: в углу, не крупнее 100×30 px
5. Обложка книги: соотношение ~2:3, с тенью/рамкой
6. Безопасная зона: 50px от краёв для обрезки в соцсетях

**Экспорт:**
- Figma-ссылка с включённым Dev Mode
- CSS-переменные для цветов
- Все используемые шрифты и их начертания

## 7. Деплой

### 7.1 MVP (бесплатный)

**Платформа:** Vercel Free Tier

**Лимиты:**
- 100 GB bandwidth/месяц
- Serverless Functions: 100 GB-hours
- Достаточно для 10-100 пользователей/день

**Деплой:**
```bash
npm install -g vercel
vercel
```

### 7.2 Продакшен (после теста)

Перенос на внутренний хостинг Ridero:
- Docker-контейнер
- Nginx reverse proxy
- PostgreSQL для трекинга
